## Development Rules (Important)

To keep this organization clean and maintainable, **all contributors must follow these rules**:

* ✍️ **Commit messages must accurately describe what was added or changed**
  *Bad:* `update`
  *Good:* `Add user authentication middleware`

* 💾 **Always commit after you finish working on a repository**
  Avoid leaving uncommitted changes or unfinished work in your local environment.

These rules help with:

* Easier debugging
* Clear project history
* Faster onboarding for new contributors

---

## Workflow Overview

1. Pick a task from the **Task List** or your **Personal Tasks** view
2. Create or update a branch as needed
3. Make focused, well-described commits
4. Commit when your work is complete
5. Review the **Roadmap** to ensure alignment with project goals
